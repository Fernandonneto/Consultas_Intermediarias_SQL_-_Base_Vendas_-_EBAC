# 🧠 Consultas Intermediárias SQL: Base de Vendas

Este projeto faz parte do Módulo Operações Básicas SQL do curso de Cientista de Dados da EBAC e tem como objetivo aprofundar o uso de SQL na análise de dados, explorando consultas de nível intermediário e técnicas de manipulação em banco de dados.

A atividade foi desenvolvida com foco em extrair informações relevantes a partir de uma base estruturada, utilizando recursos fundamentais e intermediários para análise de dados.

## 🧩 Etapas Desenvolvidas

**1. Consultas com filtros:** Utilização de cláusulas como WHERE para segmentação dos dados.

**2. Ordenação de dados:** Aplicação de ORDER BY para organização dos resultados.

**3. Agrupamento e agregação:** Uso de GROUP BY com funções agregadas (SUM, AVG, COUNT).

**4. Criação de métricas:** Desenvolvimento de indicadores a partir de cálculos e agregações.

## 📊 Resultados e Insights

- Capacidade de segmentar dados de forma mais eficiente.

- Identificação de padrões por meio de agrupamentos.

- Geração de métricas consolidadas para apoio à análise.

- Evolução na compreensão e manipulação de dados em SQL.

## ✅ Conclusão

O projeto demonstra a evolução no uso do SQL, consolidando conhecimentos intermediários importantes para análise de dados. As consultas desenvolvidas permitem extrair insights relevantes e estruturados, sendo essenciais para a atuação em Ciência de Dados.
